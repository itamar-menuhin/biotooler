# Security Policy

## Supported Versions

The following versions of biotooler are currently being supported with security updates:

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | :white_check_mark: |

## Reporting a Vulnerability

If you discover a security vulnerability within biotooler, please follow these steps:

1. **Do not** disclose the vulnerability publicly until it has been addressed.

2. **Report privately** by opening a [security advisory](https://github.com/itamar-menuhin/biotooler/security/advisories/new) on GitHub.

3. Include the following information in your report:
   - Description of the vulnerability
   - Steps to reproduce the issue
   - Potential impact
   - Any suggested fixes (optional)

4. **Response timeline**: We aim to acknowledge receipt of your report within 48 hours and will work with you to understand and address the issue.

## Security Best Practices

When using biotooler:

- Keep your dependencies up to date
- Use virtual environments to isolate packages
- Review changelogs before updating to new versions
- Report any suspicious behavior

## Dependency Security

We use Dependabot to automatically monitor and update dependencies. Security patches for dependencies are prioritized and addressed promptly.

Thank you for helping keep biotooler secure!
