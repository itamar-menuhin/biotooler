# biotooler

A Python package for bioinformatics tools.

## Installation

```bash
pip install biotooler
```

For development:

```bash
pip install -e ".[dev]"
```

## Quick Start

```python
import biotooler

# Your bioinformatics code here
```

### Running Tests

```bash
pytest
```

### Linting

```bash
ruff check .
```

### Type Checking

```bash
pyright
```

- Python >= 3.11
- biopython
- numpy
